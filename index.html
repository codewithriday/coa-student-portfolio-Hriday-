Number System Explanations

DECIMAL (Base 10)
Digits: 0–9

Standard human counting system based on positional powers of 10.

BINARY (Base 2)
Digits: 0, 1

Directly maps to physical voltage states (Low/High) in digital electronic circuits.

OCTAL (Base 8)
Digits: 0–7

Compact representation where each digit groups exactly 3 binary bits (2³ = 8).

HEXADECIMAL (Base 16)
Digits: 0–9 & A–F

Each hex digit represents exactly 4 binary bits (1 nibble, 2⁴ = 16).
